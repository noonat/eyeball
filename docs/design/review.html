A second round document, small change

Under roughly ten files and a few hundred lines the whole change is on the page and scrolling is reading. The note is third rather than buried, because on a second round it says what was done about the first one, which is the question the reviewer opens with.

  • The decision bar never scrolls away, so the length of the document has no bearing on the cost of answering it.
  • The tally is what is about to be sent. Submitting is the moment a reading becomes irreversible, and the reviewer should not have to remember how many points they made.
  • Both verdicts sit on the bar at equal size, and only one is filled. Approve is filled and on the right, under the thumb.

A large change file list, one open

Past the threshold the files come first with their counts and each expands on a tap. Both failures are real: scrolling through four thousand lines to find the interesting one, and tapping through eleven collapsed files to find the same. Selecting a line is what opens the composer.

  • The composer opens under the line it is attached to, so the code it is about is still on screen while the comment is typed. The level chips let the same text land on the file or the review instead, without retyping.
  • The refusal appears on the bar, above the buttons. Both buttons stay live: approving with no comment is a valid verdict, and only requesting changes needs something to act on.
  • A collapsed file list keeps the counts and the full path. The path truncates from the left, so the filename is what survives.

A first round with an empty base nothing marked

A document written from scratch is entirely new, and marking every passage marks none of them. It reads as a document, which is the correct reading. The toolbar has no compare control, because there is only one thing to compare against and it is empty.

  • A decided round has no decision bar and keeps a comment box. Batching protects a reading in progress, and that reading is over, so a comment written now goes out on its own immediately. The box says so rather than leaving the reviewer to guess.
  • The verdict note is shown in the same shape as the agent’s note. Both are somebody speaking about the whole thing rather than about a line of it.

An earlier round one tap away, out of the way

Comments are done once a new round starts, so they are not on the screen the reviewer opens. They are not dropped either. An earlier round keeps its comments beside what the agent did about each one, which is the only place that pairing exists.

  • A closed round has no decision bar and no comment box. It is a record. The only thing to do with it is read it, and the way back to the current round is the way in.
  • The agent’s replies are here and nowhere else. The current round carries one note saying what changed, because that is what the reviewer opens with. Per-comment answers are detail, and detail belongs where somebody went looking for it.
  • Earlier rounds are a list, not a timeline. After four rounds the reviewer wants one of them, not all of them, and a list of four rows is faster to choose from than a scroll of four transcripts.
