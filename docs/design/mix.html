  • Compare with desk.html. This sheet is that one with letter.css added after it, and nothing else changed. The letter takes the desk's tokens, so it is ink on the desk's paper, with no violet.
  • Two typefaces, each in one role. Atkinson Hyperlegible for the chrome, code and addresses. Literata for what an agent wrote and for a rendered document. The fonts together are about 215 KB, 109 for the desk's and 106 for Literata.
